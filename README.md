## **Here’s what each button does!**
Switches:
1. SW1: Same function as up arrow key on keyboard
2. SW2: Same function as down arrow key on keyboard
3. SW3: Same function as left arrow key on keyboard
4. SW4: Same function as right arrow key on keyboard
5. SW5: Same function as volume up key on keyboard
6. SW6: Same function as volume down key on keyboard
7. SW7: Same function as mute key on keyboard

There's also an OLED screen, it'll display whether the Hackpad is connected or not! It's findable as "Hackpad" when you turn bluetooth on. Seems a bit generic lol, I may want to change that.
